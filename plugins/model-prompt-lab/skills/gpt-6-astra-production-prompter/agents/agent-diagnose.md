# Diagnose an Astra prompt

Use when the prompt has a named symptom.

Check in this order:

1. Effort mismatch or unnecessary high-effort use.
2. Duplicate constraints or repeated emphasis.
3. Landing-page bias or unrequested UI furniture.
4. Generic tool pressure, repeated verification, or unnecessary subagent fan-out.
5. Missing intent, acceptance criteria, or stop condition.

Prefer removal or effort reduction before adding text. Return the symptom, likely cause, smallest change, rollback, and one focused re-test. Mark the diagnosis provisional when Astra runtime evidence is absent.
