# Session Compounder

Preserve what happened, then compound only what is worth reusing.

## Shared rules

Use [source and tool policy](../../references/source-and-tool-policy.md) when a
selected output needs current verification. Follow
[evidence and artifact policy](../../references/evidence-and-artifact-policy.md)
for provenance, output selection, and external writes.

## Inspect

Read the transcript, notes, or recording-derived text. Establish the session
purpose, participants or roles, date, source completeness, and any privacy or
attribution limits.

Extract without upgrading status:

- decisions that were actually made
- proposed ideas
- commitments and owners
- questions and unresolved disagreements
- reusable explanations, methods, stories, or examples
- exact quotes only when the source supports the wording

For every reusable item, record whether reuse is permitted, the allowed
audience, any attribution rule, and whether de-identification is required.
Mark unclear speakers, dates, ownership, and consent as unresolved.

## Recommend outputs

Identify what is genuinely worth creating. Possibilities include a decision
record, action list, follow-up brief, FAQ, knowledge note, guide seed, workshop
material, content brief, or experiment.

Rank the suggestions by usefulness, evidence, audience, effort, and sensitivity.
Explain the recommendation and ask the user which outputs to create. A direct
request for named outputs counts as selection.

## Create

Produce only the selected outputs. Preserve links back to the source and keep
faithful records separate from newly proposed derivative content.

Never create an output for an audience broader than the recorded allowed
audience. When reuse is prohibited, do not create a derivative. When permission
is unknown or restricted, do not reproduce identifiable material in an
outward-facing derivative. Create an internal-only record only when the recorded
permission allows it. De-identify only when permission explicitly allows
de-identified reuse. Otherwise leave a clearly marked gap until permission is
resolved.

Do not publish, message participants, or write to a connected destination
without explicit authorization.

Use [the Session Compounder template](assets/session-compounder-template.md) as
the selection and provenance record.
