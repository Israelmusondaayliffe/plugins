# Capability Matcher And Brief Builder

Choose against the job, then make the handoff usable.

## Required references

Read [source and tool policy](../../references/source-and-tool-policy.md) before
researching current candidates and follow
[evidence and artifact policy](../../references/evidence-and-artifact-policy.md)
for unknowns and claims. Read
[advanced execution](../../references/advanced-execution.md) before parallel
candidate research.

## Define the match

State the outcome, deliverable, required capabilities, constraints, timing,
budget if supplied, collaboration style, exclusions, and success evidence.
Separate must-haves from preferences.

## Build the candidate set

- Preserve candidates supplied by the user unless they are clearly ineligible.
- Research their current public professional evidence when the choice depends
  on current work, product features, price, or availability.
- When the user did not provide a sufficient set, search for viable current
  candidates and add stronger alternatives.
- Use only public professional information for people. Do not infer sensitive
  characteristics, private circumstances, willingness, or availability.
- Mark unverified cost, capacity, geography, and compatibility as unknown.

Independent candidate lanes may run in parallel when the set is large and the
host supports bounded agents.

## Decide

Score candidates against the same visible criteria and apply every must-have as
a qualification gate. Return one of three outcomes:

- `qualified match` with a recommended candidate and ranked shortlist
- `provisional match` pending named confirmation that could disqualify the lead
- `no qualified match` with the failed must-haves and next search or fallback

For each finalist, show evidence, gaps, tradeoffs, and disqualifiers. Do not
create false precision from thin evidence or force a winner because candidates
were supplied.

## Handoff

Create a final handoff brief only for a qualified match. For a provisional
match, create a clearly labeled draft that cannot be treated as assignment
authority. For no qualified match, provide a search or fallback brief instead.
The handoff contains:

- outcome and audience
- context and source links
- deliverables and exclusions
- constraints and permissions
- milestones or review points
- acceptance evidence
- open questions

Use [the Capability Match template](assets/capability-match-template.md).
Contacting a person, buying a product, installing a tool, or assigning external
work requires separate user authorization.
