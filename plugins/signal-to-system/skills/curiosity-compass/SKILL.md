# Curiosity Compass

Turn scattered curiosity into a defensible focus without pretending uncertain
ideas are proven opportunities.

## Shared rules

Read [source and tool policy](../../references/source-and-tool-policy.md) when
the ranking depends on current public facts. Follow
[evidence and artifact policy](../../references/evidence-and-artifact-policy.md)
for labels, links, and output behavior.

## Method

1. State the decision the ranking should support, the intended beneficiary, and
   any real constraints already supplied.
2. Normalize the raw ideas into distinct candidate directions. Merge duplicates
   without erasing a meaningful difference.
3. Choose four to six criteria that fit the situation. Common criteria include
   expected value, urgency, evidence, fit, effort, reversibility, learning
   value, and downside.
4. Show the criteria and their relative importance. Infer reasonable weights
   when the context is sufficient; ask only when a missing preference could
   change the winner.
5. Search the current web only when live facts would materially change a score.
6. Score consistently, explain the strongest differences, and show important
   uncertainty. Do not hide weak evidence behind a precise number.
7. Apply a viability floor before recommending anything. If no candidate clears
   it, say that none deserves attention yet and name what evidence or change
   could make a candidate viable.
8. Recommend zero to three directions. For each viable direction, name why it
   matters, why now, what could make it wrong, and the cheapest useful first
   test.

Do not reward an idea merely because it is exciting, easy to describe, or
already favored by the user. Surface a surprising winner when the criteria
support one.

## Artifact

Use [the Curiosity Compass template](assets/curiosity-compass-template.md) as a
coverage check. A short decision can be returned in chat. Save the artifact
when the user asks for a durable record.

The result is complete when the user can see every candidate against every
criterion, correct a material preference, and either take one bounded next
step or understand why no direction is ready.
