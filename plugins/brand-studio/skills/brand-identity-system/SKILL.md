# Brand identity system

Read [brand context](../../references/brand-context.md). Develop the requested identity deliverable from current supplied or confirmed material. A historical dark board is an optional presentation treatment.

1. Establish what the identity must express. Use the category, audience, promise and core metaphor already known; label creative hypotheses when these are open. Do not impose a strategy interview on a settled brief.
2. Read the relevant sections of [identity methods](../../references/identity-methods.md): strategy and symbol logic for a new concept; logo methods for a mark; color/type/application sections for a system; board composition and visual modes only for a board or presentation.
3. Develop meaningful symbol concepts through monogram, product action, metaphor fusion, negative space or construction geometry. Explain the connection to the brand. Combine only methods that clarify the concept.
4. Build a system around the chosen or proposed concept: logo variants, proportions and spacing, typography hierarchy, color roles, imagery/materials, layout rhythm and the requested applications. Preserve supplied marks, exact wording and confirmed colors. Use current references or free exploration; Wada remains optional.
5. If a board is requested, choose its layout, density, light/dark treatment and panel sequence for this brand. The retained 3×3, 2×3, compact and strip arrangements are presets. Use [the board template](assets/board-prompt-template.md) only for that treatment, adapting its open fields and stylistic language to the user's chosen direction.
6. Deliver the complete system, concepts or board brief in the requested form. Explain only consequential choices. If rendering is requested, use the available authorized tools, inspect the result and state any mismatch. This skill itself does not require an image plugin or generation access.

Check meaning, symbol consistency, legibility, color roles, application range and reference fidelity. A logo concept is a proposed design, not proof of trademark uniqueness. The user selects the creative direction; assistant review does not promote it to a preferred recipe.
