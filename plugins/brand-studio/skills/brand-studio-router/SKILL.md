# Brand Studio

Read [brand context](../../references/brand-context.md). Work from current supplied or confirmed material, defaulting to the user's current brand when none is named. Choose one primary skill by the requested deliverable. Start there without a compulsory strategy-to-production sequence.

| Requested result | Primary skill |
|---|---|
| Decide audience, positioning, promise, personality or brand direction | `brand-strategy` |
| Turn current decisions into a usable brief | `brand-brief` |
| Develop symbols, logo concepts, color, typography, applications or identity boards | `brand-identity-system` |
| Inspect brand consistency or identify repairs | `brand-review` |

Load the selected skill's `SKILL.md` from this plugin and complete its output. Do not run all four. A specialist can use current source material without requiring another specialist's document. If a request spans deliverables, agree or infer the smallest useful scope and deliver the requested pieces.

Keep image-prompt-only work in its current workflow. When the user explicitly asks to collaborate with Image Prompting Studio or another tool, pass a self-contained brief containing the chosen direction, source assets and open decisions. Brand work must remain usable without that tool.

Finish when the requested result is delivered, proposed choices and confirmed decisions are distinct, and any missing evidence affecting the result is stated. Generated artwork, publication and a saved preferred direction require their own requested scope.
