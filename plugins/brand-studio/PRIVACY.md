# Privacy

This package does not include telemetry, a hosted backend or a bundled MCP server. It does not transmit data to the maintainer.

The AI host processes the material you choose to provide under that host's settings and policies. Only provide material you are authorized to use. Connected tools, browsing or publication have their own permissions and privacy terms. Installing this plugin does not grant permission to access unrelated history, secrets or private files.

Use the supplied task material. Generated documents and any validation records stay in the destination selected for the task unless you separately request sharing or publication.
