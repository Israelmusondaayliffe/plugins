# Support

Maintained by the [repository owner](https://github.com/Israelmusondaayliffe/) and contributors.

Report ordinary bugs or ask usage questions through [GitHub issues](https://github.com/Israelmusondaayliffe/plugins/issues). Include the plugin version, host, the request you made, expected behavior and the observed result. Remove private content before posting.

For security concerns, use [private vulnerability reporting](https://github.com/Israelmusondaayliffe/plugins/security/advisories/new) when available. Do not post credentials or private transcripts in a public issue.

If skills are missing, confirm the marketplace and plugin are installed, then start a new task. Python-backed checks need Python 3.10 or newer. No separate paid service or API account is required for the bundled local checks.
