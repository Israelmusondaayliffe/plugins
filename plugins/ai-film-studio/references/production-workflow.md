# Eleven-Stage Film Production Workflow

1. Grill the filmmaker and resolve the creative and practical outcome.
2. Produce a complete `FilmBrief` and stop for explicit approval.
3. Break the story or script into sequences, scenes, production risks, and dependencies.
4. Establish naming, ontology, visual rules, schedule, cost limits, and the failure budget.
5. Build character, performance, voice, location, prop, costume, and state bibles.
6. Generate or edit candidate assets, stress-test them, and approve them before scene use.
7. Build geography maps, scene blocks, continuity rules, and shotlists.
8. Compile normalized `ShotRecord` data into model-specific `PromptPacket` handoffs.
9. Generate scene by scene, logging every attempt and changing one causal variable at a time.
10. Assemble the edit while generation continues, then complete cleanup, grade, dialogue, ambience, music, and effects.
11. Run delivery quality control, package project files, record lessons, and issue a `DeliveryReceipt`.

Every stage names its inputs, outputs, owner, evidence gate, cost exposure, and stop condition. Paid generation, authentication, uploads, purchases, publication, destructive replacement, and material scope expansion require separate approval.
