# Versioned Model Profiles

The profile index is a routing contract, not a live service directory.

- Seedance 2.5 is the default profile when a model-specific video prompt is requested without an explicit model selection. AI Film Studio returns a complete model-neutral packet. `video-production-studio:video-prompt-builder` may add model-specific surface syntax when installed.
- Kling and Veo require explicit selection. They are never silently substituted for another model.
- The future-model template has no live authority and cannot be promoted without current surface evidence.

Every profile requires preflight verification of the selected surface, controls, cost, and explicit approval before a live generation. A missing optional formatter leaves surface syntax and its validator result unclaimed. No profile makes a capability or availability claim on its own.
