# Source attribution and use limits

The doctrine in this plugin is an original synthesis from privately captured production, prompting, performance, and course materials supplied for this build. It is not a redistribution of those materials.

The plugin preserves only generalized production ideas: durable asset identities, explicit geography, observable performance direction, isolated iteration, and evidence-based approval.

It does not reproduce private examples, names, prompt wording, model-surface directions, screenshots, or claimed performance results.

Use this plugin as a project-owned operating guide. It does not grant rights to third-party materials, certify current model behavior, or replace direct verification on a selected tool surface.
