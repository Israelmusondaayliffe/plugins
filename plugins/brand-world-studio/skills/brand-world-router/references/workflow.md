# Brand World routing

brief: turn approved business context into a visual decision brief.
identity: create a brand kit, logo system, or visual-world board.
model-route: choose the image model and production mode for the job.
prompt-pack: create a repeatable set of generation or editing prompts.
verify: compare a series against the approved brand brief and references.

Positioning and commercial strategy stay upstream. Brand World owns visual direction, model routing, prompt production, and consistency checks.

Creative Production, Canva, Writing Quality, and Strategy Room are optional companions. Use a companion only when it is available and selected for the task.

If positioning is missing and Strategy Room is absent, write a positioning-gap handoff to `<approved-output-root>/brand-world-studio/positioning-gap.md`. Include the known context, missing decisions, unsupported claims, evidence boundaries, and exact next decision. Ask for an approved output root when none exists, keep the complete handoff in the current task until approval, and stop without inventing strategy.

When production companions are absent, keep the owned visual brief, prompt-pack, brandkit, and consistency-review path through the bundled skills.
