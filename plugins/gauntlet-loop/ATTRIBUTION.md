# Attribution

Gauntlet Loop for Codex is inspired by Matt Shumer's public description of the Gauntlet Loop and the Claude of Duty methodology.

The adapted principle is simple: define a real quality bar, separate builders from authoritative critics, let fresh critics inspect the real artifact, improve the largest remaining gap, preserve continuity, integrate the whole project, and verify completion from evidence.

This repository does not reproduce the source article. Its cross-domain project constitution, state model, schemas, scripts, templates, safety boundaries, resource envelopes, Codex invocation policy, and verification system are original implementation work.
