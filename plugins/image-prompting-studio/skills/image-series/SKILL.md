# Image Series

Read the shared [prompt contract](../../references/prompt-contract.md). Use [model profiles](../../references/model-profiles.md) only for a named model or actual execution.

Define the recurring anchor and the meaningful variation across the set. Identity can include face/hair/body, product silhouette and construction, a place's spatial features, or a coherent design language. Separate core identity from attributes the brief deliberately changes, such as wardrobe, pose, material or time.

Choose a delivery form from the request: independently copyable frame prompts, a shared session brief with frame directions, or one prompt requesting a complete set. State which form is being delivered. Consistency is the primary craft here; the number of prompt blocks must not be mistaken for the number of generated files. A contact sheet is one composite image, not multiple delivered files.

For a coherent photoshoot, preserve wardrobe rules, color treatment, environment and physical light source as needed while allowing camera, action, expression and visible lighting to develop naturally. For products, keep construction and proportions comparable. Each frame needs a reason to exist beyond cosmetic wording changes.

Use [series recipes](references/gpt-series.md) for wardrobe, product families, rooms, expression and time progression, and [collection methods](references/collection-methods.md) when making a shoot. If outputs are independent prompts, repeat the essential shared anchors accurately. If one batch prompt is requested, keep the common anchors together and enumerate each image. Do not promise perfect continuity or impose an obsolete eight-image ceiling across all models and hosts.
