# Image Storyboard

Read the shared [prompt contract](../../references/prompt-contract.md). Use [model profiles](../../references/model-profiles.md) when adapting a prompt for a named model.

Identify the story or instructional progression, recurring characters/objects, key beats and reading order. Decide from the request whether the deliverable is one page of panels, separate frames, or several pages. Declare that explicitly so a multi-panel comic is not confused with multiple image files.

Create a compact character/world anchor and give each panel a job: establish, act, react, reveal, transition or resolve. Carry props, screen direction, wardrobe and environmental continuity intentionally. Use close-ups and inserts when they serve the story; a protagonist need not appear in every frame. Separate essential story beats from optional alternative takes.

Specify per-panel action, framing, emotional change, spatial relationship, dialogue and sound-effect lettering when requested. Keep exact dialogue quoted and bubbles associated with the right speaker. Instructional steps must be physically possible and correctly ordered. Dense choreography needs clear causal beats rather than a generic action pose.

Use [narrative recipes](references/gpt-narrative.md), [Uni storyboard recipes](references/uni-storyboard.md) and [beat methods](references/beat-methods.md). A shared system-style prompt can hold continuity, but enumerate panels inside a page separately from separate image outputs. This skill delivers still-image prompts independently; it does not invoke or require Video Studio.
