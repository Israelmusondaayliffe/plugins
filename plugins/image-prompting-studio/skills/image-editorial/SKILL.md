# Image Editorial

Read the shared [prompt contract](../../references/prompt-contract.md). Use [model profiles](../../references/model-profiles.md) when adapting a prompt for a named model.

Define the page's communication job, format, audience and visual hierarchy. Gather exact copy, supplied images, desired design tradition and palette. Compose image and typography together: focal point, headline scale, negative space, supporting copy, margins, alignment and the device that makes the page recognizable.

Use a reference's observable design language without requiring a preliminary brand board. The deconstruction reference can identify idea/tension, color/material, typography, composition, visual device, grid and application logic. Turn that into the requested page; produce a separate board only when requested or useful and within scope.

Design traditions are starting vocabulary, not generic labels. Describe how their scale, rhythm, texture and layout apply to this content. Distinguish a single page or spread from a set of separate pages. Prompts for an image of a UI or slide are visual assets, not working interfaces or editable presentation files.

Use [editorial recipes](references/gpt-editorial.md) and the shared [reference deconstruction](../../references/reference-deconstruction.md). NL preserves connected art direction; JSON can help exact copy and reference separation. Check the copy inventory, hierarchy and format before delivery; assess actual legibility only after viewing a render.
