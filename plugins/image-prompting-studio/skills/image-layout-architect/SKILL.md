# Image layout architect

Make the arrangement explicit enough to guide the image: what belongs where, what overlaps, what dominates, and how the eye moves through it.

Read the [prompt contract](../../references/prompt-contract.md) for counts, formats, reference handling and delivery. When a model is named, consult only its relevant [model profile](../../references/model-profiles.md).

Inventory the required elements and exact text. Distinguish fixed positions from areas open to exploration. Establish the canvas, relative scale, foreground/midground/background, adjacency, overlap and intended hierarchy. Use a supplied layout reference as the authority for its assigned role.

Read [layout methods](references/layout-methods.md) for spatial language, composition options and task-specific treatment. Read [source layout templates](references/source-layout-templates.md) for the preserved element inventory and positional prompt forms.

Write a complete prompt in the requested form. When no count is supplied, choose a useful amount of work for the brief; do not force ten distinct compositions. For alternatives, preserve required content and explore arrangement only where allowed. Interpret percentages and coordinates as design intent unless the destination surface exposes an actual placement control.

Check that required elements appear once in their intended roles, directions and scale are consistent, text is exact, and a composite grid is not confused with separate files. Do not promise pixel-perfect placement from prose. A factual diagram also needs correct facts and relationships; a beautiful layout does not verify them.

Deliver the prompt or prompts with only the layout assumptions necessary to use them. If images are supplied for review, compare their actual placement against the brief and describe material differences. User selection determines creative acceptance.
