# Image time variation

Translate a reference or described subject into the requested time or state. Produce one transformation, a matched before/after pair, or a progression as requested.

Read the [prompt contract](../../references/prompt-contract.md) for counts, formats, reference handling and delivery. When a model is named, consult only its relevant [model profile](../../references/model-profiles.md).

Read the source as a character, object or world. Identify what remains recognizable and what the requested change actually affects. Follow the reference and user direction rather than assuming aging, seasonal change or history requires a new pose, wardrobe or setting.

Read [temporal methods](references/temporal-methods.md) for aging, time, season, weather, era, decay and renewal. For an older photograph reinterpreted today, use the preserved [modernization template](references/source-temporal-templates.md) with its change/keep choices adapted to the brief.

Write each prompt with the source description, target state or time, retained anchors, changed physical/environmental cues and coherent lighting. In a matched comparison, retain camera and composition where useful. In a narrative progression, allow purposeful changes of action and setting. Do not add unrelated temporal axes to fill an old ten-prompt preset.

Check temporal order, recognizable continuity and internal consistency of clothing, technology, architecture, weather and light. Source-ground historical claims when accuracy is part of the task; label imagined futures and uncertain reconstructions. A fictional aging image is not a prediction of a real person's appearance.

Deliver complete prompts in the requested format and count. Distinguish a sequence of separate images from a single comparison sheet. Review supplied outputs for observed drift; the user remains the final creative judge.
