# Image Campaign Grid

Read the shared [prompt contract](../../references/prompt-contract.md). Use [model profiles](../../references/model-profiles.md) when adapting a prompt for a named model.

The output is a single composite grid. Define its rows/columns, reading rhythm and intended use, then give every cell a specific role. Keep product/character recognition and the campaign's color/material language coherent while varying context, scale, framing and narrative emphasis where the brief allows.

Extract visible identity and recognition anchors from the reference. Separate the subject's physical form from its narrative associations. A product can be a hero, a macro material detail, an environmental clue or a partly occluded element when that serves the concept. Do not force luxury spaces, fashion subjects or extreme diversity onto every campaign.

Use a balanced concept bank: hero still life, macro, interaction, environmental scene, abstract material, lived activity, architectural geometry, type-led cell or atmospheric detail. Keep intentional repetition when it builds rhythm. State each cell's content and any shared border/gutter/background rules. Specify exact text if present.

Read [campaign grid methods and recipes](references/campaign-grid.md). Its source attribution to Gizem is a recorded influence, not proof she authored every template. Do not promise the model will always return the requested cell count. If an output exists, inspect cell count, repetition and visual DNA; do not label this composite as separate-image delivery.
