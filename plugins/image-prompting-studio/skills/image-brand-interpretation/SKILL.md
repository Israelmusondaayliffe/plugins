# Image Brand Interpretation

Read the shared [prompt contract](../../references/prompt-contract.md). Use [model profiles](../../references/model-profiles.md) when adapting a prompt for a named model.

Work directly from the named brand and supplied references; Brand Studio is not required. Extract observable color, materials, patterns, mark/letterform character and design language. Verify factual brand claims when needed. Distinguish proposed speculative concepts from products the brand actually makes.

Map the design intent to the relevant use case before exploring: branded product, logo treatment, packaging, mockup, apparel, poster, icon or typography. For a focused request, develop it directly. For open exploration, compare direct, adjacent, lateral and wild-card concepts without a mandatory ten-direction funnel or picking a final creative winner for the user.

Preserve the creative tension of transferring recognizable design language into a new object or context. Make the material and construction plausible for the intended medium. A sparse dark identity board, white studio product card, metallic mark or luxury object is an optional treatment, not the plugin's universal aesthetic.

Read [brand design catalog](../../references/patterns/brand-design-catalog.md), [brand DNA](../../references/patterns/brand-dna-extraction.md), [brand creative directions](../../references/patterns/creative-directions-brand.md), and [architecture patterns](references/brand-patterns.md) only as needed. Use [reference deconstruction](../../references/reference-deconstruction.md) to derive a transferable visual system when requested; no compulsory board-generation step.

Keep exact marks/copy and source facts distinct from creative invention. A generated mark is not guaranteed production-perfect. Deliver the requested prompt set and let the user choose which recipes become preferred references.

The [preserved brand concept recipes](references/nano-brand.md) retain the original direction and prompt structures. Use them as templates rather than a required scoring/selection funnel.

For an identity overview image, the optional [identity-board recipe](references/identity-board-recipe.md) retains the original brandkit layout and symbol/application prompt. Choose its treatment only when it fits the requested image; a dark or sparse board is one option, not a fixed aesthetic. This recipe is complete inside Image Prompting Studio and requires no Brand Studio handoff.
