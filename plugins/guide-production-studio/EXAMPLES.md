# Three example tasks

These prompts are adapted from real work patterns. They are reusable demonstrations, not claims that this public version produced the original work. Provide the stated inputs before running each example.

## 1. Turn official model documentation into a practical guide

Inputs: Provide the official documentation links and intended reader.

```text
Use guide-production-studio:guide-production-router to build a practical prompting guide from these official sources. Start with the reader's task. Map the sources, propose the structure and build one sample section before drafting the rest. Include useful examples, source links and the date the information was checked. Flag unsupported claims and stop before publication.
```

Expected result: A source map, reader-focused structure and reviewable sample section, followed by the approved guide.

## 2. Explain a visual workflow tool to a team

Inputs: Provide the official tool documentation and your approved brief templates.

```text
Use guide-production-studio:guide-source-mapper and guide-production-studio:practical-guide-architect to plan a guide to this visual workflow tool. Explain what context the tool can see, how to brief it, common failure cases and how to use the supplied templates. Distinguish tested practices from untested suggestions. Include source and permission notes for shared assets. Stop after the outline for approval.
```

Expected result: A traceable source map and practical outline ready for approval.

## 3. Check a participant guide before sharing

Inputs: Provide the complete participant guide and workshop outcome.

```text
Use guide-production-studio:guide-acceptance-review to read this participant guide as someone new to the topic. Find places where the reader lacks context, a term is unexplained or an instruction cannot be followed. Quote each passage, explain the difficulty and propose a concrete fix. Preserve useful detail and exact prompt blocks. Return the review without changing or publishing the guide.
```

Expected result: A reader-focused acceptance review with actionable findings and publication still under user control.
