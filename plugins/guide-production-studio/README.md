# Guide Production Studio

Guide Production Studio owns practical guide production. It turns approved sources, tested workflows, and rights-safe evidence into guides people can understand and use.

It solves a different problem from prose cleanup. Writing Quality can polish final sentences, but this plugin owns source lineage, teaching architecture, examples, visual evidence, reader usefulness, and human acceptance.

## Workflow

1. Map sources and public provenance.
2. Choose a guide architecture from the reader's job.
3. Build one benchmark before scaling.
4. Review independently as a reader.
5. Stop at human approval before publication or bulk production.

## Boundaries

- It does not publish to Notion, Discord, or another external destination.
- It does not invent examples, results, workflow history, or platform behavior.
- It does not expose private plugin names or implementation sources in public material.
- It does not suppress legitimate public provenance merely because private implementation details also exist.
- It does not let a producer approve their own guide.

## Reliability

Scripts validate contracts, review records, bundle structure, and obvious public-output leakage. Human judgment remains responsible for teaching quality, voice, usefulness, and final approval.
