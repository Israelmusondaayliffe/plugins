# Review phase

## Scope

Explain and adjudicate staged proposals. Do not execute the destination change.

## Workflow

1. Run the report command and read the cited signal records.
2. Separate repeated patterns from one-offs and mentions from real tool use.
3. Approve, reject, or leave staged with a concise reason.
4. Record the decision through the CLI.

## Output

Return proposal IDs, destinations, evidence counts, and decisions. Hand approved items back to the front door.
